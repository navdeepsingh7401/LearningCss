# Results summary component

A responsive results summary card built with semantic HTML, CSS, and vanilla JavaScript.

## Features

- Responsive two-column desktop layout that stacks on smaller screens
- Gradient score panel and category-colored summary rows
- Locally hosted Hanken Grotesk fonts
- Summary scores generated from a JavaScript data array, with the overall score calculated as their average
- Keyboard-visible focus styling for the Continue button

## Run locally

Open `index.html` in a browser. The component loads its styles from `style.css` and its icons and fonts from `assets/`.

## Project files

- `index.html` contains the component markup and score data.
- `style.css` contains the layout, colors, typography, and responsive styles.
- `assets/` contains the icons and font files used by the component.
