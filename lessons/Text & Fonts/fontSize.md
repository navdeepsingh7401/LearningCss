# Font Size

The `font-size` property controls the size of text.

## Basic Syntax

```css
p {
    font-size: 18px;
}
```

## Common Units

```css
h1 {
    font-size: 2rem;
}

p {
    font-size: 16px;
}
```

Common units include:
- `px`
- `rem`
- `em`
- `%`

## Example

```css
body {
    font-size: 16px;
}

h2 {
    font-size: 32px;
}
```

## Summary

Use `font-size` to make text larger or smaller so it is readable and visually balanced.
