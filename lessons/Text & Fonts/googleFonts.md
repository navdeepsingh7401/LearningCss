# Google Fonts / Web Fonts

Google Fonts lets you use many free custom fonts in your website.

## 1. How to Add Google Fonts

Add this link inside the `<head>` section of your HTML file:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Poppins:wght@400;700&display=swap" rel="stylesheet">
```

## 2. Use the Font in CSS

```css
body {
    font-family: 'Poppins', sans-serif;
}
```

## Why Use Web Fonts?

- better design
- more variety of fonts
- improved website style

## Example

```css
h1 {
    font-family: 'Poppins', sans-serif;
    font-weight: 700;
}
```

## Summary

Google Fonts and other web fonts help make your website look modern and unique without installing fonts on the computer.
