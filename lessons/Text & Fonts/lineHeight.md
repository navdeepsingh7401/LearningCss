# Line Height

The `line-height` property controls the space between lines of text.

## Basic Syntax

```css
p {
    line-height: 1.6;
}
```

## Why It Matters

A good line height improves readability.

## Example

```css
p {
    font-size: 18px;
    line-height: 1.8;
}
```

## Common Values

- number: `1.5`
- unit values: `20px`
- percentage: `150%`

## Summary

`line-height` improves the vertical spacing between lines and makes paragraphs easier to read.
