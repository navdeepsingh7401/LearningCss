# Font Family

The `font-family` property defines which font is used for text.

## Basic Syntax

```css
body {
    font-family: Arial, sans-serif;
}
```

This means:
- use `Arial` if available
- otherwise use a generic sans-serif font

## Common Font Families

```css
p {
    font-family: 'Times New Roman', serif;
}
```

Other common options:
- `Arial, sans-serif`
- `Verdana, sans-serif`
- `Georgia, serif`
- `Tahoma, sans-serif`
- `'Courier New', monospace`

## Example

```css
h1 {
    font-family: 'Segoe UI', sans-serif;
}
```

## Summary

`font-family` changes the typeface of text and helps create the overall style of a webpage.
