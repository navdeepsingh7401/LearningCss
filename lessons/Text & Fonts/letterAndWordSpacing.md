# Letter Spacing and Word Spacing

These properties control the space between letters and words.

## 1. Letter Spacing

```css
h1 {
    letter-spacing: 2px;
}
```

This adds space between each letter.

## 2. Word Spacing

```css
p {
    word-spacing: 5px;
}
```

This adds space between words.

## Example

```css
.heading {
    letter-spacing: 3px;
}

.text {
    word-spacing: 6px;
}
```

## Summary

Use `letter-spacing` and `word-spacing` to improve typography and make text feel more open or decorative.
