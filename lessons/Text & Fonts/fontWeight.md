# Font Weight

The `font-weight` property controls how bold or light the text appears.

## Basic Syntax

```css
p {
    font-weight: normal;
}

h1 {
    font-weight: bold;
}
```

## Common Values

- `normal`
- `bold`
- `bolder`
- `lighter`
- `400`
- `500`
- `700`
- `900`

## Example

```css
.title {
    font-weight: 700;
}

.subtitle {
    font-weight: 400;
}
```

## Summary

`font-weight` helps create hierarchy in text, such as headings being bolder than paragraph text.
