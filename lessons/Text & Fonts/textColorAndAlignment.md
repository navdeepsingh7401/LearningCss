# Text Color and Alignment

Text color and alignment are two of the most basic ways to style text in CSS.

## 1. Text Color

Use the `color` property to change the text color.

```css
p {
    color: blue;
}
```

You can use:
- color names: `red`, `blue`, `green`
- hex values: `#ff0000`
- rgb values: `rgb(0, 0, 255)`

## 2. Text Alignment

Use `text-align` to align text horizontally.

```css
h1 {
    text-align: center;
}
```

Common values:
- `left`
- `center`
- `right`
- `justify`

## Example

```css
p {
    color: darkslategray;
    text-align: justify;
}
```

## Summary

- `color` changes text color
- `text-align` changes horizontal text position

These properties help improve readability and layout.
