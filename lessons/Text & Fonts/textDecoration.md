# Text Decoration

The `text-decoration` property adds visual decoration to text.

## Common Values

```css
p {
    text-decoration: underline;
}
```

Other values:
- `none`
- `underline`
- `overline`
- `line-through`

## Example

```css
a {
    text-decoration: none;
}

h2 {
    text-decoration: underline;
}
```

## Summary

`text-decoration` is useful for links, headings, and special text effects.

For example:
- remove underline from links
- underline headings
- strike through text for cancelled items
