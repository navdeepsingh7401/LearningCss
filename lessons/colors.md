# CSS Colors

Colors are used to change the look of text, backgrounds, borders, and other elements.

## 1. Basic Color Names

You can use color names directly.

```css
p {
    color: red;
}
```

Example color names:
- red
- blue
- green
- black
- white
- purple

## 2. Hex Colors

Hex colors use a `#` symbol followed by 6 characters.

```css
h1 {
    color: #ff5733;
}
```

Examples:
- `#000000` = black
- `#ffffff` = white
- `#ff0000` = red

## 3. RGB Colors

RGB means Red, Green, Blue. Each value is between 0 and 255.

```css
.box {
    background-color: rgb(0, 128, 255);
}
```

## 4. HSL Colors

HSL means Hue, Saturation, Lightness.

```css
.card {
    color: hsl(210, 100%, 50%);
}
```

## 5. Common Color Properties

```css
h2 {
    color: blue;
}

button {
    background-color: green;
}

div {
    border-color: red;
}
```

## Summary

CSS colors can be written in different ways:
- color names
- hex values
- rgb()
- hsl()

Colors are used to make webpages more attractive and readable.
