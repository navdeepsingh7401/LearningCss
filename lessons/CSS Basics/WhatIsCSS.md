# What Is CSS?

CSS stands for Cascading Style Sheets. It is a language used to style and design web pages, while HTML creates the structure of a webpage. CSS controls how that structure looks.

## Example

```css
h1 {
    color: blue;
    font-size: 30px;
}
```

This CSS makes all `<h1>` elements blue and sets their font size to 30px.

## CSS Can Control

- color
- font
- spacing
- animations
- responsive design
- layout and positioning
- other visual effects

CSS is what makes a webpage look clean, attractive, and modern.
