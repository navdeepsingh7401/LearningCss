# Learning CSS

This project is a simple CSS learning notebook for basic front-end styling concepts.

## CSS Basics Covered

- What is CSS?
- CSS syntax
- Inline, internal, and external CSS
- CSS comments and selectors
- Colors
- Backgrounds
- Borders
- Width and height
- CSS units (`px`, `%`, `em`, `rem`, `vh`, `vw`)
- Text color and alignment
- Font family
- Font size
- Font weight
- Line height
- Letter and word spacing
- Text decoration
- Google Fonts / web fonts
